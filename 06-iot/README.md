# Internet of Things (IoT)

## 📌 Overview

During my internship at Monk9 Tech, I studied the fundamentals of Internet of Things (IoT) and how connected devices communicate, collect data and interact with the physical environment.

The training helped me understand the relationship between sensors, embedded systems, communication technologies and intelligent applications.

## 📚 Topics Covered

- IoT fundamentals
- IoT architecture
- Sensors and actuators
- Connected devices
- Data acquisition
- Device-to-device communication
- Wireless communication
- IoT protocols
- Embedded systems in IoT
- IoT applications
- IoT security fundamentals

## 🔗 IoT Architecture

A basic IoT system can be understood through the following stages:

Sensors & Devices
↓
Data Collection
↓
Communication
↓
Data Processing
↓
Application / Monitoring

## 🧠 Learning Experience

Through technical sessions and learning activities, I developed an understanding of how physical devices can be connected to communication networks for monitoring, data collection and intelligent applications.

## 🎯 Learning Outcome

I gained a foundational understanding of IoT architecture, connected devices, sensors, communication and real-world IoT applications.
