# Monk9 Tech — Internship Tasks & Assessments

## 📌 Overview

During my internship at Monk9 Tech, I participated in structured technical training, laboratory activities and assessments related to VLSI, semiconductor technology and digital systems.

The internship included technical sessions, practical learning activities, GitHub and Linux labs, task-based learning and two assessments.

## 📅 Training Activities

### Day 1 — Physical Design Overview

- Introduction to VLSI Physical Design
- Understanding the physical design flow
- Introduction to important physical design stages
- Relationship between digital design and physical implementation

### Day 2 — GitHub & Linux Overview

- Introduction to GitHub
- Repository and README concepts
- Introduction to Linux
- Basic Linux commands
- Understanding development environments

### Day 3 — Floorplanning, GitHub & Linux Labs

- Fundamentals of Floorplanning
- GitHub laboratory activities
- Linux laboratory activities
- Task-based technical learning

## 🧪 Internship Tasks

The internship included structured tasks related to:

- GitHub profile and README creation
- GitHub repository management
- Linux fundamentals
- VLSI Physical Design
- Semiconductor Technology
- Digital Electronics
- Embedded Systems
- IoT
- AI/ML fundamentals
- Verilog and RTL concepts

## 📝 Assessments

Two assessments were conducted during the internship to evaluate understanding of the technical concepts covered during the training.

The assessments helped reinforce the concepts learned through technical sessions and learning activities.

## 🧠 Learning Experience

The task-based approach helped me connect theoretical concepts with practical learning activities and understand how different technologies are connected within the electronics and VLSI domain.

## 🎯 Learning Outcome

The internship strengthened my technical foundation in semiconductor technology, VLSI, physical design, embedded systems, IoT, AI/ML, Linux and GitHub.
