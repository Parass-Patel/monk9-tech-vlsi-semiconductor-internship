# Monk9 Tech — VLSI & Semiconductor Internship

## 📌 Internship Overview

This repository documents my learning journey and technical exposure during my internship at Monk9 Tech.

The internship provided structured learning in Semiconductor Technology, VLSI, Physical Design, Digital Electronics, Embedded Systems, IoT, AI/ML, Verilog, RTL Design, Linux and GitHub.

The program also included an industrial visit, technical sessions, hands-on learning activities and two assessments.
