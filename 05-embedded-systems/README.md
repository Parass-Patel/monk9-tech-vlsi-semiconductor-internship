# Embedded Systems

## 📌 Overview

During my internship at Monk9 Tech, I studied the fundamentals of embedded systems and their role in modern electronic products and intelligent devices.

The training introduced me to microcontrollers, embedded architectures, sensors, programming concepts and hardware-software integration.

## 📚 Topics Covered

- Embedded system fundamentals
- Microcontrollers
- Microprocessor vs Microcontroller
- Embedded system architecture
- Sensors and actuators
- Input and output interfaces
- Hardware-software integration
- Real-time embedded systems
- Embedded applications
- Introduction to IoT-based embedded systems

## 🔧 Microcontroller Concepts

The training provided an overview of microcontroller-based systems and how controllers interact with sensors, peripherals and external devices.

## 🧠 Learning Experience

Through technical sessions and learning activities, I developed a basic understanding of how embedded hardware and software work together to perform specific tasks.

## 🎯 Learning Outcome

I gained a foundational understanding of embedded systems and their applications in electronics, automation, IoT and intelligent devices.
